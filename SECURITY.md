# Security Policy

## Supported versions

Security fixes are applied to the current `main` branch and production deployment. Older local checkouts are not maintained separately.

## Reporting a vulnerability

Do not open a public issue containing exploit details, credentials, private repository data, or personal information.

Use GitHub's **Report a vulnerability** option on this repository. If private vulnerability reporting is unavailable, contact the maintainer through the contact method on the maintainer's GitHub profile without including sensitive details in the first message.

Include the affected page or API route, reproduction steps using placeholder data, the possible impact, and a suggested fix if available.

This repository must never contain GitHub tokens or other credentials. The public solution JSON files are expected to be readable; secrets and private user data are not.
